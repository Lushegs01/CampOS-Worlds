# Combat Arena audio: sources and licences

Generated by `scripts/assets/build-arena-audio.mjs` from `scripts/assets/arena-audio/sources.mjs`. Every recording listed here is used by at least one runtime sound bank in `public/assets/arena/audio/`; the banks are edits of these recordings (cuts, filters, level, pitch for a part's size, layers).

CC BY and CC BY-SA works require attribution; CC BY-SA also requires that the derived sounds (the edited clips inside the banks that use them) are shared under the same licence. Those banks are listed per source, so the obligation is clear: the game code is not a derivative of the sounds.
